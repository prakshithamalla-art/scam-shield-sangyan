# Solution Overview

## What Scam Shield does
Scam Shield is a free, no-login web tool. A user pastes a suspicious SMS, WhatsApp message, email text or link. In about a second it returns:
- a **risk level**: Safe (green), Suspicious (yellow), High risk (red)
- a **score out of 100**
- the **specific red flags** found, each explained in plain language
- **what to do next**, plus a one-tap link to **cybercrime.gov.in** and the **1930** helpline

## How it helps investors
- Turns vague unease ("this feels odd") into a concrete reason ("it asks for OTP and rushes you").
- Teaches while it protects: every flag is a small lesson users carry to the next message.
- Works in **English, Hindi and Telugu**, including romanized Hinglish and mixed-script messages.

## User journey
1. Receives a worrying message about KYC, a "guaranteed" tip, or a prize.
2. Opens Scam Shield and picks a language (EN | हिं | తె).
3. Pastes the message (or only the link) and taps **Check now**.
4. Sees a large coloured badge, an animated score and the red flags found.
5. Reads the recommendations: do not click, never share OTP, verify through official channels.
6. If risky, taps **Report to cybercrime.gov.in**.

## Why it is different
| Existing options | Scam Shield |
|---|---|
| Generic antivirus / link scanners check URLs only | Analyses **message language and intent** and URLs together |
| English-only advisories | **Hindi and Telugu**, built into the engine, not just translated labels |
| Dense security jargon | Big buttons, icons, plain words, high contrast |
| Black-box AI verdicts | **Transparent rules**: every point of the score is explained |
| May store submissions | **Nothing stored**, nothing logged, URLs are never fetched |

## Guardrails
No stock tips, no price predictions, no broker or product promotion. Results always say they are guidance, not proof.
